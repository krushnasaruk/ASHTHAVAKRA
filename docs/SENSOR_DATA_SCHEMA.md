# H10 — Sensor Data Schema

All data payloads in H10 adhere strictly to formal JSON Schemas located in `shared/schemas/`.

---

## 1. Schema Hierarchy
1. **Sensor Packet (`shared/schemas/sensor_packet.json`):** Single-frame telemetry packet representing instantaneous 5-finger flex and 6-DOF IMU state.
2. **Calibration Record (`shared/schemas/calibration.json`):** Two-point baseline calibration per channel (open vs closed values, span, polarity, timestamp).
3. **Repetition (`shared/schemas/repetition.json`):** Segmented kinematic event representing a single repetition with duration, peak excursion, hold time, and smoothness.
4. **Session Record (`shared/schemas/session.json`):** Complete patient exercise session including aggregate metrics, quality gate results, pain/fatigue ratings, and nested repetitions.
5. **Rehabilitation Plan (`shared/schemas/plan.json`):** Clinician-prescribed exercise targets, versioning metadata, and safety criteria.
6. **Patient Record (`shared/schemas/patient.json`):** Pseudonymized demographic and impairment baseline record.
7. **Clinical Flag (`shared/schemas/flag.json`):** Rule-based movement alerts generated by the system for clinician review.
8. **Feature Schema v1 (`shared/schemas/feature_schema_v1.json`):** 84-dimensional feature vector format for ML exercise recognition.

---

## 2. Core Entities

### 2.1 Sensor Packet Schema
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "H10SensorPacket",
  "type": "object",
  "required": ["timestamp_ms", "flex", "imu", "flags", "battery_pct"],
  "properties": {
    "timestamp_ms": { "type": "integer", "minimum": 0 },
    "flex": {
      "type": "array",
      "items": { "type": "integer", "minimum": 0, "maximum": 4095 },
      "minItems": 5,
      "maxItems": 5
    },
    "imu": {
      "type": "array",
      "items": { "type": "integer" },
      "minItems": 6,
      "maxItems": 6
    },
    "fsr": { "type": "integer", "minimum": 0, "maximum": 4095, "default": 0 },
    "flags": { "type": "integer", "minimum": 0, "maximum": 255 },
    "battery_pct": { "type": "integer", "minimum": 0, "maximum": 100 }
  }
}
```

### 2.2 Calibration Record Schema
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "H10CalibrationRecord",
  "type": "object",
  "required": ["id", "patient_id", "timestamp", "fingers", "is_valid"],
  "properties": {
    "id": { "type": "string" },
    "patient_id": { "type": "string" },
    "timestamp": { "type": "string", "format": "date-time" },
    "is_valid": { "type": "boolean" },
    "fingers": {
      "type": "array",
      "minItems": 5,
      "maxItems": 5,
      "items": {
        "type": "object",
        "required": ["name", "open_value", "closed_value", "span", "polarity"],
        "properties": {
          "name": { "type": "string" },
          "open_value": { "type": "number" },
          "closed_value": { "type": "number" },
          "span": { "type": "number", "minimum": 300 },
          "polarity": { "type": "integer", "enum": [1, -1] },
          "stability_sd": { "type": "number" }
        }
      }
    }
  }
}
```

### 2.3 Session Record Schema
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "H10SessionRecord",
  "type": "object",
  "required": [
    "id", "patient_id", "exercise_code", "plan_version",
    "started_at", "ended_at", "duration_s", "reps_completed",
    "reps_target", "mean_rom", "max_rom", "pain_after",
    "fatigue_after", "data_quality", "data_source"
  ],
  "properties": {
    "id": { "type": "string" },
    "patient_id": { "type": "string", "pattern": "^P-[0-9]{3,}$" },
    "exercise_code": { "type": "string" },
    "plan_version": { "type": "integer", "minimum": 1 },
    "started_at": { "type": "string", "format": "date-time" },
    "ended_at": { "type": "string", "format": "date-time" },
    "duration_s": { "type": "number", "minimum": 0 },
    "reps_completed": { "type": "integer", "minimum": 0 },
    "reps_target": { "type": "integer", "minimum": 1 },
    "mean_rom": { "type": "number", "minimum": 0, "maximum": 100 },
    "max_rom": { "type": "number", "minimum": 0, "maximum": 100 },
    "consistency": { "type": ["number", "null"], "minimum": 0, "maximum": 100 },
    "fatigue_drop_pct": { "type": ["number", "null"] },
    "pain_before": { "type": ["integer", "null"], "minimum": 0, "maximum": 10 },
    "pain_after": { "type": "integer", "minimum": 0, "maximum": 10 },
    "fatigue_before": { "type": ["integer", "null"], "minimum": 0, "maximum": 10 },
    "fatigue_after": { "type": "integer", "minimum": 0, "maximum": 10 },
    "data_quality": { "type": "string", "enum": ["good", "reduced", "invalid"] },
    "data_source": { "type": "string", "enum": ["real", "simulated"] },
    "note": { "type": "string" }
  }
}
```
